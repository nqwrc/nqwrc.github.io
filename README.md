# nqwrc.github.io

Nicola's (nqwrc) personal portfolio landing page — a single static `index.html` linking to
`warehouse-kpi-dashboard`, `transport-performance-analysis` and `qa-reporting-pipeline`.

## goal
Give a recruiter one URL that explains what the three data projects are and links to each,
in support of `nqwrc.career`'s G1 goal (site and dashboard deployed).

## kpi
None — this is evidence for M0, not an independently measured project. G0/G1 in
`nqwrc.career` already measure it. Declared deviation from the 1-3 KPI rule.

## kill
`nqwrc.career` is signed and closed (M0), or the portfolio direction changes.

## how
Single `index.html`, no build step. Deploys as GitHub Pages once pushed to `main` on the
`nqwrc/nqwrc.github.io` repo (a `<username>.github.io` repo auto-publishes).
